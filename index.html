Got questions about Project Echo? Here are the ones we hear most.

What is Project Echo?
Project Echo is a free OG Fortnite revival server. It recreates Chapter 1 with authentic gameplay, the original map, classic weapons, and a working Battle Pass, available on PC, Xbox, and iOS.
How do I download and install Echo?
Download the Echo Launcher from the button on this page. It installs in a few clicks, downloads the correct game version automatically, and keeps everything up to date whenever a patch drops.
Is Project Echo completely free?
Yes, completely free. Every season, every Battle Pass tier, and every mode is available without spending anything. Optional Supporter Packs help keep the servers running and come with cosmetic rewards.
Is it safe? Can I get banned from Epic?
Echo operates independently from Epic Games and does not interact with your official Epic account or Fortnite installation. Accounts authenticate via Discord, no passwords stored. Thousands of players use it without issue.
